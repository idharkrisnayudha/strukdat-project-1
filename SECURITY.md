# Kebijakan Keamanan (Security Policy)

## Ruang Lingkup Proyek
Repositori ini merupakan proyek akademik untuk mata kuliah struktur data.

## Pelaporan Bug Kritis & Memory Issue
Jika Anda menemukan celah keamanan, *memory leak*, *dangling pointer*, atau *segmentation fault* pada implementasi pointer:
1. Buat laporan baru melalui menu **Issues** dengan menggunakan template **Bug Report**.
2. Jelaskan langkah-langkah untuk mereproduksi error beserta *input data* yang memicu masalah tersebut.
3. Jangan menyertakan data kredensial pribadi atau file konfigurasi lokal ke dalam repositori.
